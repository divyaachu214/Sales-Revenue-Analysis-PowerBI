# 📊 Sales and Revenue Analysis Dashboard | Power BI

## 📌 Project Overview

This project focuses on analyzing sales performance and revenue insights using **Microsoft Power BI**. The interactive dashboard provides a clear overview of business performance through key performance indicators (KPIs) and data visualizations.

The dashboard helps understand revenue trends, product performance, regional sales, and category-wise revenue distribution.

## 🎯 Project Objectives

- Analyze overall sales and revenue performance.
- Track total revenue, quantity sold, and total orders.
- Identify top-performing products.
- Compare revenue across different regions.
- Understand category-wise revenue contribution.
- Present business insights through interactive visualizations.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query
- DAX (Data Analysis Expressions)
- Data Visualization
- Data Analytics

## 📈 Dashboard Features

### 1. Key Performance Indicators (KPIs)
- Total Revenue
- Total Quantity
- Total Orders

### 2. Revenue Analysis
- Revenue trends over time.
- Monthly sales performance.

### 3. Product Analysis
- Revenue by Product.
- Product performance comparison.

### 4. Regional Analysis
- Revenue by Region.
- Regional sales comparison.

### 5. Category Analysis
- Revenue by Category.
- Category-wise contribution.
